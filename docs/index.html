멘티가 자주 막히는 지점

미리 알고 있으면 세션이 훨씬 매끄럽습니다.

  • 상태 파일 — 로컬 state로 시작했다가 backend로 옮길 때 terraform init -migrate-state에서 대부분 한 번 막힙니다
  • IAM 신뢰 정책 — 권한 정책과 신뢰 정책의 구분이 안 되면 크로스 계정에서 전부 무너집니다
  • SOPS — KMS 키 권한이 없으면 복호화가 조용히 실패합니다
  • Atlantis Webhook — HTTPS·인증서 문제로 PR 이벤트가 안 들어오는 경우가 가장 흔합니다
  • EKS 접근 제어 — Access Entry를 안 걸어두고 kubectl이 안 된다고 하는 상황
